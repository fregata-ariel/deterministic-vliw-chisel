# Verilator 5.024 の挙動

#87（親: #85）の結果。方法とチェック項目の定義は [VERILATOR_VERSIONS.md](../VERILATOR_VERSIONS.md#方法) にある。測定は GitHub Actions の `ubuntu-24.04` の runner（`.github/workflows/verilator-catalog.yml`）で行った。第1段は `sbt test` などと race（各構成 10000 回）、第2段は race の `-j 0` だけを 60000 回（20 shards）で、CPU ごとに数えた。

## 5.024

ロックの再試行を50000回に増やしただけの緩和。runner（70000 回）と手元の Intel（10000 回）で abort は観測されなかったが、ソースの上では abort の経路が残っている。

| # | 項目 | 結果 |
|---|---|---|
| A | ビルド | 成功、4 分 30 秒（4 CPU）、コンパイラの警告 3 件（g++ (Ubuntu 13.3.0-6ubuntu2~24.04.1) 13.3.0） |
| B | race（`-j 0`） | issue 4931 の abort **0/70000**（abort の出た shard 0/25）、ほかの abort・エラー 0 |
| C | race（`--build-jobs 0 --verilate-jobs 1`） | issue 4931 の abort **0/10000**、ほかの abort・エラー 0 |
| D・G・I | `sbt test`（ADR-0013 の対処あり） | 成功、288 秒。ChiselSim のビルド 53 回。`hw` と `crosscheck`（RTL と参照モデルの差分テスト）を含む |
| E | `sbt test`（対処なし、`-j 0`） | 成功、278 秒; 成功、244 秒 |
| H | `%Warning` | なし |

B の比較の基準は、ソースからビルドした 5.020 の `-j 0`（29/70000、abort の出た shard 6/25）。この版の abort が基準より少ないことの片側 Fisher 検定は、回数の合算で p = 1.9e-09、abort の出た shard の数で p = 0.011。shard（runner）ごとに頻度が大きく違うので、回数を合算した検定は甘くなる。shard の数の検定の方が頑健である。

CI の runner は CPU の種類も機械も選べない。同じ機械で版を比べるため、cloud のコンテナ（Intel Xeon @ 2.80GHz、4 CPU、15 GB）で、同じ設計の verilation を `-j 0` で繰り返した。

## ソースの変更点（前の版 5.020 から）

- **スレッドプール**: デストラクタが `try_lock` を最大 `VL_LOCK_SPINS`（50000）回、`VL_CPU_RELAX()` を挟んで繰り返すようになった（`Fix try-lock spuriously fails (#4931) (#4938)`）。sleep せず、待たずに回すだけなので、ロックが長く取られていれば abort する経路は残る。
- **乱数・seed・jobs・svsim が使う C++ API**: 5.020 と同じ。svsim の使うオプション（`--cc --exe --build -o --top-module --Mdir --assert --timescale -CFLAGS +define -F`）は削除も改名もされていない。
- **言語**: IEEE 1800-2023 が既定になった。予約語は増えていない。
- **正しさの修正**: `V3Const` の bit-op-tree 最適化の誤コード生成（NOT 部分木、EQ/NEQ の極性、シフト）。5.020 では一部の AND/OR/NOT/EQ/シフトの式が誤る可能性があった。`_vl_insert_WI` が wide（64 ビット超）の書き込み先の1ワード先まで書く不具合。`$time` の丸め。
- **実行時**: `verilator_bin` が成功時に統計レポートを標準出力に出すようになった。生成モデルが `Verilated::stackCheck()` でスタックの大きさを確かめ、足りなければ警告を出す。
- **ビルド**: `make install` の配置が変わった（実体が `share/verilator/bin`、`bin/` は Perl のスタブ）。`--enable-m32` が廃止された。ubuntu-24.04 の g++ 13 で足りる。

調査の方法: 調査エージェントの報告 15 件を、別のエージェントが git のオブジェクトを読んで反証しようとした: 確認 15、反証 0、不確実 0。報告の全文（証拠のコード引用つき）と、検証が見落としとして挙げた項目は、[`research/5.024.json`](research/5.024.json) にある。
