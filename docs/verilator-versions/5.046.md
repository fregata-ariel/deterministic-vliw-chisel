#97（親: #85）の結果。方法とチェック項目の定義は [VERILATOR_VERSIONS.md](../VERILATOR_VERSIONS.md#方法) にある。測定は GitHub Actions の `ubuntu-24.04` の runner（`.github/workflows/verilator-catalog.yml`）で行った。第1段は `sbt test` などと race（各構成 10000 回）、第2段は race の `-j 0` だけを 60000 回（20 shards）で、CPU ごとに数えた。

## ソースの変更点（前の版 5.044 から）

- **乱数の実装が替わった**: `$urandom`/`$random` の PRNG が、Xoroshiro128+（状態の両語に seed を入れ、32 ビットの popcount が 10 未満なら反転）から、**Xoroshiro128\*\* と SplitMix64 による seed 化**に替わった。seed ありでもなしでも、すべての値が変わる。seed なしの実行は、これまでどおり毎回同じ（`randSeed() == 0` のとき、未初期化の `lrand48()` から作る）。実測（`$urandom` を4回）: seed なし `73b2233c a107c0d1 613e3743 aadb0c9a`、seed 1 `b722072d fd8d9d77 24800459 5fa24450`（5.044 までの seed 1 は `8084023f f77f7fff ff7fffff fffffffc` で、1 のビットが多かった）。新しいシステム関数 `$get_initial_random_seed()` が `randSeed()` を返す。
- **スレッドプール・終了処理・jobs**: 変更なし。0 は `VlOs::getProcessDefaultParallelism()` を意味する。
- **svsim**: `--xml-only`、`--xml-output`、`--make cmake` が削除された（svsim は使わない）。`--top-module` の値が `AstNode::encodeName()` を通る（`svsimTestbench` は変わらない）。`simulation-driver.cpp` が使う C++ API は同じ。
- **実行時のセマンティクス**: `vl_stop()` は、`$finish` 済みなら、メッセージも `exit(1)` もなしで即座に返る。並行アサーションの `disable iff` の条件は、サンプル値でなく現在値を使う（IEEE どおり）。`__Vm_didInit` を `_eval_static`/`_eval_initial`/`_eval_settle` の後で true にする。declaration initializer のある static 変数がループの中でも1回だけ初期化される。
- **正しさの修正**: `V3Life` が、exported DPI 関数で書かれうる変数を、DPI 呼び出しをまたいで定数伝播しなくなった（svsim は DUT を DPI で読み書きする）。
- **警告・エラー**: `IMPLICITSTATIC` が initial/final の中の初期値つき宣言にも出る。`MULTIDRIVEN` が、タスク経由の書き込みも検出する。2状態と4状態の unpacked 配列の代入がエラー。（実測: 警告なし）
- **その他**: `V3Reloop` の局所変数の登録漏れ（5.044 の `--inline-cfuncs` で重複宣言の C++ コンパイルエラーになりえた）の修正。自動変数がトレースに書かれなくなった。
