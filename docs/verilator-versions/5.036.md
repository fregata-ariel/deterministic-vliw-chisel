## ソースの変更点（前の版 5.034 から）

- **スレッドプール・終了処理**: 変更なし。
- **jobs**: `--output-groups` の既定が `--build-jobs`（なければ `-j`）の値になった。svsim の `--build-jobs 0` は `hardware_concurrency()` なので、この環境（4 CPU）では C++ の出力が4つのグループに分かれる。
- **乱数・seed**: 変更なし。
- **警告**: 新しい警告 `DEFOVERRIDE`（既定オン）。コマンドラインで定義済みのマクロを、ソースで `` `define `` すると出る。svsim は `+define+` を使うが、firtool の出力は同じマクロを定義しない（実測: 警告なし）。
- **実行時のセマンティクス**: エッジ検出や変化検出に使う「前の値」の変数が、`_eval_static`（initial ブロックの前）で初期化されるようになった。時刻0の initial による posedge が、論理を起動するようになる。
- **正しさの修正**: unpacked 配列の 'FlagShared' 方式の NBA の誤コード生成（5.030〜5.034 にあった。firtool のメモリ `reg [w:0] Memory[0:d]` が対象）。automatic の局所変数が呼び出しごとに既定値に戻る。
- **最適化**: `-fvar-split` が既定でオン。
- **ビルド**: tcmalloc の static ライブラリが `--whole-archive` でリンクされ、`verilator_bin` の malloc を本当に置き換えるようになった（このカタログのビルドは tcmalloc を使わない）。
- **その他**: VCD/FST が、値の変化がない時刻の行を書かなくなった。

調査の方法: 調査エージェントの報告 11 件を、別のエージェントが git のオブジェクトを読んで反証しようとした: 確認 11、反証 0、不確実 0。報告の全文（証拠のコード引用つき）と、検証が見落としとして挙げた項目は、[`research/5.036.json`](research/5.036.json) にある。
