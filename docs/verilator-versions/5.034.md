## ソースの変更点（前の版 5.032 から）

- **スレッドプール・終了処理**: 変更なし。
- **jobs**: `--build-jobs`・`--verilate-jobs` の既定値（1）を決める場所が、`parseOptsList()` の最後から `V3Options::notify()` に移った。`-f`・`-F` のファイルの中の `-j` が、先に処理されたときに無視される不具合の修正。
- **乱数・seed**: 変更なし。seed なしの `$urandom` は純粋のまま（seed つきの `$urandom(seed)` だけが除去できなくなった）。
- **svsim**: オプションも C++ API も同じ。`+incdir+` の値が `+` で分割されるようになった（svsim は、include のディレクトリを設定したときだけ出す。このプロジェクトでは設定していない）。DPI の `context` 関数の呼び出しで、`AstScopeName` を2重に付けない修正が入った（svsim のテストベンチは DPI の context import/export を使う）。
- **警告**: 新しい警告 `COVERIGN`（サポートしない covergroup などが `E_UNSUPPORTED` から移る）。Chisel の cover は `cover property` になり、サポート済みの構文なので影響しない。
- **正しさの修正**: `V3Simulate`（定数関数の評価）が AstConst の再利用に `user1` を使い、ほかの値と衝突していた。`force` の代入を `V3Life` が最適化して、`force` の後の読み出しが古い値を返す不具合。
- **ビルド**: configure が `-Wno-subobject-linkage` を C++ のフラグに足した（g++ の警告を抑える）。

調査の方法: 調査エージェントの報告 13 件を、別のエージェントが git のオブジェクトを読んで反証しようとした: 確認 13、反証 0、不確実 0。報告の全文（証拠のコード引用つき）と、検証が見落としとして挙げた項目は、[`research/5.034.json`](research/5.034.json) にある。
