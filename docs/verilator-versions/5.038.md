## ソースの変更点（前の版 5.036 から）

- **スレッドプール・終了処理・jobs**: 変更なし。
- **svsim**: `--assert` が既定でオンになった（svsim は元から渡す）。`--assert` は `assert-case` も明示的にオンにする。`simulation-driver.cpp` が使う C++ API は同じ。
- **乱数・seed**: `$urandom`・`+verilator+seed+` の扱いは変更なし。X 初期値（`--x-initial unique`、既定）と `--x-assign unique` の一時変数が、共有のスレッド RNG でなく、変数ごとの PRNG（`randSeed ^ hash(インスタンス名) ^ hash(変数名)`）から値を取るようになった。`+verilator+rand+reset+` を有効にしたときだけ関係する。
- **正しさの修正**: DFG の定数畳み込みで、符号付きの `<=` が `<` として畳まれていた（両辺の定数が等しいと誤り）。定数のシフト量が 32 ビットを超える算術シフト、`V3Expand` の C++ の幅などの修正。`case` の式が符号なしの項目と比べられるとき、符号拡張でなくゼロ拡張になる（IEEE どおり）。
- **警告**: `PROCASSINIT`（style、オフ）が新設。未知の `/*verilator ...*/` コメントは `BADVLTPRAGMA`（waiver できる pretend-error）になった。
- **最適化**: 'scoped' DFG pass と `binToOneHot`（65 個以上の `==CONST` が同じ源を共有するとき）が既定でオン。
- **その他**: パーサのシンボルテーブルを外して、型名を非型として再宣言できるようにした（SystemVerilog の入力すべてで構文解析の違いが出うる）。VCD の `emitTimeChange` の segfault の修正（5.036 の重複タイムスタンプの最適化に由来）。

調査の方法: 調査エージェントの報告 19 件を、別のエージェントが git のオブジェクトを読んで反証しようとした: 確認 19、反証 0、不確実 0。報告の全文（証拠のコード引用つき）と、検証が見落としとして挙げた項目は、[`research/5.038.json`](research/5.038.json) にある。
